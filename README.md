# TaskManager — тестовое задание iOS

Основная логика управления задачами находится в `ServiceTask`; приложение на UIKit показывает список задач и позволяет менять их статус.

Разбор первого пункта и исправленный пример находятся в [Задание 1 - EmployeeTask.swift](<Задание 1 - EmployeeTask.swift>).

## Управление задачами

`ListTaskModel` содержит `UUID`, название, описание, дату создания, приоритет и статус выполнения. `ServiceTask` хранит задачи в массиве и предоставляет все семь операций из задания:

| Операция | Метод |
| --- | --- |
| Добавить задачу | `createTask` |
| Удалить по идентификатору | `deleteTask` |
| Изменить статус | `updateStatus` |
| Получить все задачи | `getAllTasks` |
| Получить завершённые | `getCompletedTasks` |
| Отфильтровать по приоритету | `getPriorityTasks` |
| Отсортировать по дате создания | `getSortDateTasks` |

При добавлении сервис создаёт `UUID` и дату. Удаление и изменение статуса выбрасывают ошибку, если задача не найдена. Выборки возвращают пустой массив, когда совпадений нет. Сортировка возвращает новый массив с более новыми задачами в начале и не меняет порядок хранения.

Интерфейс демонстрирует получение списка и изменение статуса. Остальные операции доступны в сервисе и проверяются тестами. Данные хранятся только в памяти и исчезают после перезапуска приложения.

## Запуск и проверка

Откройте `TaskManager.xcodeproj` в Xcode и выберите схему `TestTask`. Тесты сервиса находятся в `TestTaskTests/TestTaskTests.swift`; запустите `TestTaskTests` через Test Navigator. Пять тестов проверяют все семь операций, в том числе ошибки при неизвестном идентификаторе и сохранение исходного порядка после сортировки.
